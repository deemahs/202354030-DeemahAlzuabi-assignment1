# AI Usage Report

## 1. Tools Used & Use Cases

### ChatGPT

I used ChatGPT as an AI-assisted development and learning tool during this assignment.

I used ChatGPT for several purposes throughout the development process.

### Understanding the Assignment

I used ChatGPT to help me understand the assignment requirements and divide them into smaller tasks.

This helped me identify the main requirements, including the About Me section, Projects section, Contact form, responsive design, JavaScript interactivity, GitHub repository, and documentation.

### Website Planning

I used ChatGPT to get suggestions for organizing the portfolio as a single-page website.

I decided to organize the website into sections that users can navigate between using buttons and navigation links.

### HTML Assistance

ChatGPT provided suggestions for organizing the HTML structure using elements such as sections, navigation links, project cards, and a contact form.

I reviewed and customized the content to better represent my personal portfolio.

### CSS and UI Design

I used ChatGPT to help understand and apply CSS Grid, Flexbox, and media queries.

I also requested design changes and customized the website to rearrange the placement of texts 

### JavaScript Assistance

ChatGPT helped explain how JavaScript can be used to add interactive features.

I used JavaScript to implement features such as the dark/light theme.

### Documentation

I used ChatGPT to help organize and fix grammar mistakes in the README, AI usage report, and technical documentation.

I reviewed the documentation and made sure that it reflected the actual implementation of my project.

## 2. Benefits & Challenges

### Benefits

Using AI helped me understand the assignment requirements more clearly and organize the development process.

It provided useful examples and explanations for HTML, CSS, JavaScript, and responsive design.

AI also helped me explore different design ideas and understand how different front-end technologies work together.

Another benefit was that I could ask follow-up questions when I did not understand a requirement or technical concept.

It also helped me discover knew features that I can do using HTML, CSS, JavaScript. 

### Challenges

AI-generated suggestions are not automatically correct or suitable for every project.

Some suggestions needed to be changed to match the assignment requirements and my preferred design.

For example, I changed the structure and appearance of the portfolio and selected my own preferred design specification.

I also needed to test the website myself because AI suggestions cannot replace actual browser testing.

## 3. Learning Outcomes

Through this assignment, I improved my understanding of front-end web development.

I learned how HTML is used to structure a webpage and how CSS controls its layout and appearance.

I practiced using CSS Grid and Flexbox to organize content.

I also learned how media queries allow a website to adapt to desktop, tablet, and mobile screen sizes.

Using JavaScript helped me better understand event listeners, DOM manipulation, and how JavaScript can change CSS classes dynamically.

The dark/light mode feature helped me understand how HTML, CSS, and JavaScript can work together to create an interactive user experience.

I also learned how AI can support software development while still requiring the developer to review, understand, modify, and test the generated suggestions.

## 4. Responsible Use & Modifications

I used AI as a supporting tool rather than submitting its suggestions without reviewing them.

I reviewed the generated HTML, CSS, and JavaScript and made changes based on the assignment requirements and my personal preferences.

I customized the website content to represent my own academic background, skills, projects, and experiences.

I also customized the design, including the pink, black, and white color palette and the organization of the website sections.

I tested the interactive features and responsive layout to check that the website worked correctly.

This process helped ensure that I understood the final solution and used AI responsibly and transparently.
